# Visual Knowledge

AI-powered context management platform that gives AI tools persistent, visual context.

## The Problem

AI tools lack persistent context. Every conversation starts from scratch - users re-explain the same context over and over.

## The Solution

Visual Knowledge provides **entity-centered panels** that organize and persist context for AI interactions.

### Core Concepts

- **Tables** - Collections of related entities (e.g., "Sales Pipeline", "Job Candidates")
- **Rows** - Individual entities within tables (e.g., "Acme Corp", "Jane Doe")
- **Panels** - Visual context cards attached to rows (Notes, Research, Gmail, etc.)

When you chat with AI about an entity, all relevant context is automatically included.

## Features

- **Persistent Context** - Context lives with your data, not in chat history
- **Visual Panels** - See all context at a glance in a card-based UI
- **AI Integration** - Context automatically fed to AI conversations
- **Gmail Integration** - Pull relevant emails into entity context
- **Research Panels** - AI-generated research attached to entities
- **BYOK** - Bring your own API keys for AI providers

## Tech Stack

- Next.js 16
- TypeScript (strict mode)
- Supabase (auth, database, realtime)
- TanStack Query
- shadcn/ui
- Vercel AI SDK
